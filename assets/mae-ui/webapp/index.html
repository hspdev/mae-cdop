Architecture Overview
🏗 Strategy Pattern
IBulkJobHandler with 4 specialized handlers per job type
🏭 Factory Pattern
HandlerFactory with runtime registration
🔄 Retry Framework
Exponential backoff: 1s / 2s / 4s, max 3 retries
🗄 Batch Query
Chunked IN-clause SQL (500 records/chunk)
📦 7-Step Pipeline
REQUEST → VALIDATING → LOADING → PROCESSING → VERIFYING → GENERATING → COMPLETED
🤖 AI Recovery
Auto-heals failed records using pattern matching
